# Shiv Modi

Personal portfolio for Shiv Modi, a software engineer focused on backend development and applied machine learning.

Live site: [shivmodi21.github.io](https://shivmodi21.github.io/)

## About

A single-page static site. No build step or dependencies. HTML, CSS, and JavaScript.

Sections: About, Skills, Experience, Education, Projects, Certifications, Publications, and Contact.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Structure

```
index.html          page content
style.css           layout and styling
script.js           navigation and interactions
images/             photos and favicon
logo/               logos
resume/             resume PDF
```
